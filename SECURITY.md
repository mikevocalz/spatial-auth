# Security policy

This repository is pre-release identity infrastructure. Report suspected account takeover, credential exposure or proof verification bypass **privately** to the repository maintainers via GitHub's private vulnerability reporting feature if enabled; otherwise contact the project owner through a private trusted channel. Do not publish exploitable details or real credentials in an issue.

Please include affected version/commit, provider, reproduction steps with test identities, expected vs actual behavior and the minimum safe logs. Real Meta/PICO/OIDC tokens and Snap handoff tickets must be redacted. Do not exploit third-party accounts. The full threat model and release controls are in [docs/SECURITY.md](docs/SECURITY.md).
